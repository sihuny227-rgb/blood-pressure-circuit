# 혈압 조절 회로도

심장(펌프), 세동맥(수도관), 신장(관리소)과 이 셋을 조종하는 신경·호르몬이 혈압을 어떻게 지키는지 보여 주는 교육용 시뮬레이터입니다. 고혈압에서 어디가 고장 나는지, 혈압약이 어디를 막는지 한 장의 회로도와 움직이는 장기 그림으로 따라갈 수 있습니다.

**바로 열기:** https://sihuny227-rgb.github.io/blood-pressure-circuit/

## 무엇을 볼 수 있나

| 탭 | 내용 |
| --- | --- |
| 1. 정상 조절 | 혈압이 떨어질 때(출혈·탈수)와 오를 때, 압수용체 반사(초) → RAAS(분~시간) → 신장의 나트륨·수분 조절(시간~일)이 차례로 작동하는 과정을 단계별로 재생 |
| 2. 고혈압의 문제 부위 | 염분 민감형·비만형·스트레스형·노인 수축기 단독형·원발성 알도스테론증 등 환자 유형과 7가지 기전, 혈압을 올리는 약(NSAIDs, 코막힘약)을 켜면 고장 부위가 빨갛게 표시됨. 압력-나트륨이뇨 곡선과 표적장기 손상 위험 |
| 3. 약물의 표적 | ARB, ACE 억제제, CCB, 티아지드, 베타차단제, MRA의 표적 위치(초록 핀)와 약해진 경로, 치료 전후 혈압, 예상 상대위험 감소, 병용 시 주의점. **부작용은 왜 생길까**: 약별 부작용 22가지를 "약의 작용 → … → 부작용" 단계로 풀어 설명하고, 생기는 위치를 회로도에 주황 점선으로 표시 |

회로도 아래의 **장기 들여다보기**에서는 지금 상태의 값으로 장기가 움직입니다.

- **심장 · 좌심실 단면**: 심박수에 맞춰 수축하고, 고혈압이 이어지면 벽이 두꺼워짐(좌심실 비대)
- **대동맥**: 맥박의 물결에 따라 늘었다 줄었다 하고, 경직되면 잘 늘어나지 않음
- **세동맥**: 평활근 수축·이완으로 굵기가 바뀜. Ca²⁺ 유입(수축)과 내피 NO(이완), CCB 차단 표시
- **신장 · 네프론**: 걸러진 Na⁺이 세뇨관을 지나며 재흡수되는 모습, 레닌·알도스테론, 티아지드(NCC)·MRA(MR) 표적

## 실행 방법

`index.html` 파일 하나로 동작합니다. 위의 웹 주소로 열거나, 파일을 내려받아 브라우저로 열면 됩니다. 글꼴은 Google Fonts에서 불러오며, 인터넷이 없으면 시스템 글꼴로 표시됩니다.

## 주의

환자 교육과 약학 학습을 위한 참고 자료입니다. 혈압 수치는 각 기전의 방향과 상대적 크기를 보여 주도록 만든 단순 모델의 결과이며, 개인의 실제 혈압이나 치료 반응을 예측하지 않습니다. 네프론 그림은 움직임이 보이도록 소변으로 나가는 나트륨 비율을 과장했습니다. 실제 약물 선택은 동반 질환, 임신 여부, 신기능, 칼륨, 부작용을 함께 고려해 의료진이 결정합니다.
